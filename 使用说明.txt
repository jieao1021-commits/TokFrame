============================================================
                抖窗 TokFrame  软件介绍与使用说明
============================================================

【软件名称】抖窗 TokFrame
【软件版本】v1.0
【运行文件】TokFrame.exe（单文件，约 958KB，无需安装）


────────────────────────────────────────────────────────────
一、软件简介
────────────────────────────────────────────────────────────

抖窗 (TokFrame) 是一款独立的桌面浏览器，专门为抖音网页版设计。

双击启动后直接进入抖音网页版（https://www.douyin.com），
没有地址栏、没有标签页、没有边框，整个窗口就是一页抖音。

主要特点：

  1. 无边框：没有任何系统标题栏，全部界面由黑色顶栏和网页组成
  2. 黑色顶栏：Edge 风格，整条顶栏可拖动窗口，右侧四个窗口按钮
      （置顶 ⇧ 、最小化 — 、最大化/还原 □ 、关闭 ✕）
  3. 支持 Windows 贴靠分屏：拖到屏幕边缘 / 顶部 / 四角即可分屏
  4. 打开即进入抖音网页版，视频自动播放
  5. 自动记住窗口位置和大小，下次打开恢复
  6. 单文件免安装，内嵌全部运行库（WebView2 依赖已打包在 EXE 内）
  7. 单实例运行：重复双击只会唤醒已打开的窗口


────────────────────────────────────────────────────────────
二、使用方法
────────────────────────────────────────────────────────────

【启动】
  双击 TokFrame.exe 即可（桌面快捷方式同样有效）。

【拖动窗口】
  按住顶部黑色导航栏的任意位置拖动即可移动整个窗口。
  双击顶栏可以在「最大化 / 还原」之间切换。

【调整窗口大小】
  鼠标移到窗口的四边或四角（约 8 像素感应区），出现缩放光标后拖动。

【窗口按钮】
  顶栏右侧四个按钮（从左到右）：
     ⇧  窗口置顶（保持最前，再次点击取消；激活时图标变为青色）
     —  最小化
     □  最大化 / 还原
     ✕  关闭

【Windows 贴靠分屏】
  拖动顶栏到屏幕：
     左边缘或右边缘  →  窗口半屏
     顶部            →  最大化（Win11 会出现布局选择）
     四个角          →  四分之一屏
  也可以使用 Win + 方向键 实现分屏。

【从任务栏还原】
  最小化后，点击 Windows 任务栏上的窗口图标即可还原。

【快捷键】
  F11           全屏 / 退出全屏（全屏时自动隐藏顶栏，同 Edge 行为）
  Ctrl+W        关闭窗口
  Alt+F4        关闭窗口
  Ctrl+Shift+K  清理缓存（保留登录状态，推荐偶尔使用）
  Ctrl+Shift+L  清除全部浏览数据（包括登录状态，会退出抖音登录）


────────────────────────────────────────────────────────────
三、缓存与登录说明
────────────────────────────────────────────────────────────

  日常无需手动清理缓存：浏览器内核（Chromium）会自动淘汰旧缓存，
  缓存大小不会无限增长；抖音登录状态也会在服务端自动过期。

  建议：
   · 感觉页面加载变慢时，按 Ctrl+Shift+K 清缓存，不会影响登录
   · 想彻底重置浏览器（退出登录），按 Ctrl+Shift+L 清除全部数据
   · 如遇异常，退出浏览器后删除以下目录可完全重置：
       %LOCALAPPDATA%\DouyinBrowser\

  登录状态、缓存等数据保存在：
       %LOCALAPPDATA%\DouyinBrowser\WebView2Data


────────────────────────────────────────────────────────────
四、系统要求
────────────────────────────────────────────────────────────

  Windows 11     直接使用（系统自带 WebView2 运行时）
  Windows 10     可用；如提示缺少 WebView2 运行时，
                 安装微软官方「WebView2 Evergreen Runtime」
                 一次即可（多数 21H2 及以上版本已自带）
  Windows 7 / 8  不支持（WebView2 运行时官方已停止支持 Win7/8）

  另需 .NET Framework 4.8（Windows 10 1903+ 与 Windows 11 系统自带）。


────────────────────────────────────────────────────────────
五、常见问题
────────────────────────────────────────────────────────────

  问：任务管理器里为什么有 msedgewebview2.exe 进程？
  答：这是浏览器内核的辅助进程，属于微软 WebView2 共享运行时。
      在「进程」页签中它们显示在「抖窗 (TokFrame)」应用分组之下，
      属于正常现象。

  问：网页里的视频不自动播放？
  答：本程序已开启自动播放策略；若某些视频仍需点击，
      通常是网页自身策略（带声音的视频需一次交互），点击即可。

  问：登录后下次打开还需要重新登录吗？
  答：不需要。登录状态保存在本地，除非手动执行 Ctrl+Shift+L
      清除全部数据或删除数据目录。

  问：抖音站外的链接会怎么打开？
  答：站外链接自动交给系统默认浏览器打开，不会离开本程序。

  问：首次运行时 Windows 提示「Windows 已保护你的电脑」？
  答：这是 Windows SmartScreen 对未做数字签名的程序的正常提示，
      不代表程序有问题。点击提示框中的「更多信息」，
      再点「仍要运行」即可。如果杀毒软件提示风险，
      选择「允许运行 / 添加信任」即可。

  问：程序能否放在任意位置？
  答：可以。TokFrame.exe 是单文件程序，放在哪里都能运行；
      首次运行会自动解压所需 DLL 到 %LOCALAPPDATA%\DouyinBrowser\。


────────────────────────────────────────────────────────────
六、彻底删除软件（完全清理）
────────────────────────────────────────────────────────────

  本软件为绿色免安装程序，没有卸载程序，删除文件即彻底卸载。

  步骤：

  1. 关闭软件
       按 Ctrl+W 或 Alt+F4，或点击顶栏右侧的关闭按钮（✕）。

  2. 删除程序文件
       删除整个软件目录（例如 D:\TokFrame\ 文件夹），
       即删除 TokFrame.exe 和使用说明.txt 等全部文件。

  3. 删除用户数据（登录状态、缓存、解压出的运行库）
       删除以下目录：
           %LOCALAPPDATA%\DouyinBrowser\
       操作方法：在资源管理器地址栏输入 %LOCALAPPDATA% 并回车，
       找到 DouyinBrowser 文件夹，整个删除即可。
       该目录包含：
           WebView2Data\       登录状态与浏览器缓存
           WebView2Loader.dll  首次运行时自动解压的运行库

  4. 删除桌面快捷方式（如创建过）
       删除桌面上的「抖音浏览器」图标即可。

  5. 完成
       本软件不写注册表、不安装系统服务、不设置开机启动，
       也不产生其他系统残留。完成以上删除后即彻底清除。

  补充说明：
   · 仅删程序文件、保留数据目录时，重新放置 TokFrame.exe 运行
     会自动沿用原来的登录状态和数据。
   · 仅想退出登录而不删除程序，使用 Ctrl+Shift+L 清除全部数据即可。
   · 想换一台电脑使用：把 TokFrame.exe 拷到新电脑即可；
     需要迁移登录状态时，同时拷贝 %LOCALAPPDATA%\DouyinBrowser\ 目录。
